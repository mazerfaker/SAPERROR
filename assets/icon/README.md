# Official SAPERROR icon
Upload the original `saperror.png` (1254x1254 RGBA, SHA256 25e8ffa77a10ef61ff4fd8bdca4d709f8026b2a0084543f767ee744a0228e52f) and the exact prepared `SAPERROR.ico` (seven sizes, SHA256 356fd921fa4c9de6b7a8f8ddbaa53d89ba8919e37d0fc1aac11cbd6e8c965d44) together. The approved source artwork is never regenerated. CI now requires both files and verifies the exported executable icon. The native window/taskbar setting is configured in project.godot. On Windows the actual taskbar/shortcut appearance must still be checked manually.
