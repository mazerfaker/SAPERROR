# SAPERROR Analytics — opt-in rollout
Private dashboard: https://saperror-analytics.vergil1705200.workers.dev. Public ingestion accepts valid session summaries with rate limits; the dashboard remains authenticated. No API credentials in the game. Pilot versions are rejected and old pilot records excluded from all aggregates until normal expiry. New v4 consent is required; prior pilot consent does not enable telemetry. See [privacy notice](../PRIVACY.md).

Dashboard: 1/7/14/30 days, version filters, sessions, active time, average session, outcomes, win rate, daily graphs and mode breakdown. Day graphs group by session start (UTC); totals select last update. Sessions are not unique players. All data approximate and client-reported. Public endpoint cannot prevent all fabricated submissions. No persistent client queue; no headless traffic. Revocation cancels pending request and clears state; accepted records expire after 30 days of inactivity. Provider backups may differ.

Deploy through explicit analytics/deploy.request on visual-foundation. GitHub secrets CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN and SAPERROR_DASHBOARD_PASSWORD. Never print secrets. Disable ingestion with INGEST_ENABLED=false and matching deploy/smoke settings if needed. Release gate: owner must verify controller details and applicable privacy requirements; manually test actual Windows opt-in, opt-out, revocation and offline behavior before public release. Automated tests do not replace these checks.
