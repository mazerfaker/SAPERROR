## Українська
SAPERROR — завершена за обсягом однокористувацька гра-сапер у стилі analog horror для Windows x64. Версія 1.0.0 для особистого некомерційного використання, на основі RC9. Не публічний реліз.

### Можливості
- Кампанія: 4 акти, 10 секторів, WATCHER, LIAR, LOOP, ADMIN, 3 кінцівки.
- Classic, Anomaly Lab, Free Run та Endless; 4 складності, навчання з 9 етапів.
- Оригінальне живе оточення, CRT, DOS-завантаження, авторська музика, затверджені звукові ефекти.
- Українська й англійська, доступність, налаштування зображення/звуку, збереження з відновленням.
- Retro98 Setup, portable ZIP. Добровільна аналітика за явною згодою, гра працює офлайн.

### Встановлення
Розпакуй Setup ZIP і запусти SAPERROR_Setup.exe або розпакуй весь Windows x64 ZIP та запусти SAPERROR.exe поруч із SAPERROR.pck. Не потрібна інсталяція Godot. Збереження у %APPDATA%/Godot/app_userdata/SAPERROR/; зроби резервну копію перед оновленням. Аналітика вимкнена без згоди, її можна відкликати в налаштуваннях приватності.

### Перевірки й обмеження
RC9 пройшла автоматичні тести Windows і Analytics. Фінальна збірка 1.0.0 підлягає окремому CI. Ручне тестування на ПК власника не виконано; реальна передача статистики новим клієнтом на production не підтверджена. Права на розповсюдження окремих аудіоресурсів не підтверджені. ## English
SAPERROR is a feature-complete single-player analog-horror minesweeper roguelite for Windows x64. Version 1.0.0 is a personal, noncommercial private-use build based on RC9, not a public release.

### Features
- Campaign: four acts, ten sectors, WATCHER, LIAR, LOOP, ADMIN, three endings.
- Classic, Anomaly Lab, Free Run and Endless; four difficulties, nine tutorial stages.
- Original live environment, CRT effects, DOS boot, original score and approved sound effects.
- Ukrainian/English, accessibility, display/audio settings and recoverable saves.
- Retro98 Setup and portable ZIP; explicit opt-in analytics, offline gameplay.

### Installation
Extract Setup ZIP and run SAPERROR_Setup.exe, or extract the entire Windows x64 ZIP and run SAPERROR.exe next to SAPERROR.pck. Godot installation is not required. Back up saves in %APPDATA%/Godot/app_userdata/SAPERROR/ before upgrading. Analytics is disabled without consent and can be revoked in Privacy settings.

### Verification and limitations
RC9 passed automated Windows and analytics checks. The 1.0.0 build requires separate CI. Owner hardware testing was not performed; real production delivery from the latest client is unconfirmed. Redistribution rights for some audio assets remain unresolved. Keep archives private; see LICENSES.md and PRIVACY.md. SHA256SUMS.txt verifies archive integrity, not a digital signature.
