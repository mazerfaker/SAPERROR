# CRT refinement — fixed projection (crt.2)
User rejected the crt.1 geometry deformation visible at 100%. CRT intensity must change optical/electronic appearance only, never UI position, size, aspect ratio, primary sampling coordinates or pointer mapping. Primary sample is texture(TEXTURE,UV); halo uses symmetric neighbor samples only for glow. Glass mask and background PNG are unchanged. Optional glass shading replaces the old curvature switch; legacy curve setting is ignored. Scanlines, dither, phosphor halo, noise, fault and outcome tint are confined to the CRT. Boot/shutdown use luminance masking, not geometric transforms. Separate scene filter remains opt-in and independent.
