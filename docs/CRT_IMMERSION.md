# CRT Immersion v0.2.3-alpha
Boot is a 2.4-second presentation, not a real BIOS diagnostic. ESC, Enter or Space skip it; no board clicks are forwarded until ready. Shutdown collapses the display over 0.65 seconds and fades the hum. Reduced-motion setting bypasses shutdown animation and dynamic outcome tint; initial boot remains skippable. Outcome banners are non-interactive and transient; actual board outcome remains visible in status. CRT mask, primary UV transform, approved PNG and board core are untouched. Headless runs skip initial boot; lifecycle model and UI integration checks do not prove rendered appearance. Manual Windows checks remain necessary.
