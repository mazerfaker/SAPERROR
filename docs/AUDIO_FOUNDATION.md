# Audio Foundation v0.2.2-alpha
Original deterministic synthesized mono 16-bit PCM at 22050 Hz, generated in memory. No licensed third-party audio. Six bounded AudioStreamPlayer voices plus one continuous periodic hum. The game only requests gameplay sounds for real state changes; loss/win take priority over reveal. Effects and hum levels and master mute are session-only. No actual playback in headless tests; PCM format, levels, determinism and loop boundaries are tested, but Windows listening, volume balancing and visual QA remain manual gates. No source art or board logic modifications.

## 0.5.0-alpha.1-audio.1
Hum now uses 48000 Hz PCM, 60-second phase-locked buffer built from the original two-second periodic formula. One native forward-looping player; no periodic restart, fade-to-zero gap or new click. The PCM wrap and derivative are checked; actual sound-card playback over multiple minutes is still a manual test. The dedicated menu-click stream is the exact supplied MP3 (see assets/audio/README.md); non-menu effects retain the old procedural sounds and existing volume controls. If asset is absent the old menu sound remains as a temporary fallback. No changes to lamp sound, board, CRT or live background.
