# Campaign foundation
0.6.0-alpha.1: GDD four acts, ten sectors. Clear ordinary sector 3, 6 or 9 then complete existing authored WATCHER, LIAR or LOOP challenge. Campaign rewards one unique memory record per boss; trial-local HP and free restart are provisional, no additional credits. Returning from boss restarts encounter but preserves completed sector and records. At sector 10 ADMIN gate stops the unfinished campaign. Route choices, checkpoints, actual optional archives, full LOOP boss phases, ADMIN, endings and credits remain open. Existing Free Run and Anomaly Lab preserved. No intermediate CI; Beta regression includes campaign metadata and UI route tests. Rollback cf1f7ee.
