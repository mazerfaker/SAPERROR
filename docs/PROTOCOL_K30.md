# PROTOCOL K-30 (developer-only)
Hidden sequence uses physical keycodes and ignores echoes, held keys and modifiers. Only active unfinished CLASSIC boards accept it. During animation UI input is locked; mark live mines first, retain already-neutralized mines, then reveal only known safe tiles one at a time in a separate administrator helper. No hit or HP changes; normal BoardState and solver unchanged. Victory is counted through the existing outcome handler; standard victories and K-30 share the next-sector route. Classic sessions are open-ended, not campaign progression: next sector keeps difficulty and advances seed deterministically, requiring normal first click. Pending next sector and sector number are stored with session state; an interrupted override before victory restores the last ordinary saved board. No resources, campaign, final-sector or anomaly system currently exists, so integration/test of those features is deferred. Reduced motion suppresses signal glitches and scan wave; log and safe reveal remain. Code is not advertised in player help, tutorial or settings. Headless QA verifies logical layout independence with synthetic key events, not actual physical keyboards. Windows visual/audio acceptance remains manual.

Input hotfix: K-30 receives key events in the gameplay root _input before GUI forwarding, independent of CRT focus. Only activation/active protocol consumes the key; other controls retain their normal path. Partial input resets on window focus loss.
